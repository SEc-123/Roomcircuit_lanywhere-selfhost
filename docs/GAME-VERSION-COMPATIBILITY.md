# Game updates and Local Wireless

The public room list shows the game update reported by the host. To share your room's update version, open RoomCircuit from Album or Ultrahand while hosting. Rooms without a report show a dash.

The game controls admission. If RoomCircuit can verify both updates and finds a documented conflict for the same title, it asks you to match versions before selecting the room.

| Game | Published Local Wireless compatibility |
| --- | --- |
| Mario Kart 8 Deluxe | Version 4.0.1 cannot match with earlier versions. Version 1.4.0 cannot match with 1.2.1 or earlier. [Nintendo update notes](https://www.nintendo.com/en-gb/Support/Nintendo-Switch/Game-Updates/How-to-Update-Mario-Kart-8-Deluxe-1482895.html) · [Earlier updates](https://en-americas-support.nintendo.com/app/answers/detail/a_id/26098/) |
| Super Smash Bros. Ultimate | Local Wireless Battles require matching software versions. [Nintendo update notes](https://www.nintendo.com/en-gb/Support/Nintendo-Switch/Game-Updates/How-to-Update-Super-Smash-Bros-Ultimate-1484130.html) |
| Pokémon Scarlet and Violet | Players need matching software updates. [Nintendo update notes](https://www.nintendo.com/en-gb/Support/Nintendo-Switch/Game-Updates/How-to-Update-Pokemon-Scarlet-and-Pokemon-Violet-2299678.html) |
| Splatoon 3 | The Shoal's 3.1.0 and 6.0.0 updates each break compatibility with their earlier versions. [Nintendo update history](https://www.nintendo.com/en-gb/Support/Nintendo-Switch/Game-Updates/Splatoon-3-Update-History-2358763.html) |
| Super Mario 3D World + Bowser’s Fury | Version 1.2.2 supports local play with 1.2.1, 1.2.0 and 1.1.0. It is incompatible with 1.0.0. [Nintendo update notes](https://www.nintendo.com/en-gb/Support/Nintendo-Switch/Game-Updates/How-to-Update-Super-Mario-3D-World-Bowser-s-Fury-1920668.html) |
| Bayonetta 2 | Version 1.2.0 supports local play with 1.1.0. It is incompatible with 1.0.0. [Nintendo update notes](https://support.nintendo.com/jp/switch/software_support/ae98a/120.html) |

For other version pairs, select the room normally and let the game check compatibility. The game also checks the active edition when both Pokémon Scarlet and Violet are installed. To check your installed update, highlight the game on HOME and press **+**.
