RoomCircuit, formerly LANywhere Self-host, helps players find rooms, test nodes, and schedule sessions for Switch Local Wireless games over the internet.

## English

- Renamed the app and overlay to **RoomCircuit** and added the three-console icon.
- Redesigned the lobby as a game list beside a room table.
- Showed plain game names and made long focused titles scroll.
- Expanded the node picker with regions, measured latency, and clear availability.
- Grouped appointments by game and kept scheduled times in the console's local time.
- Used the Switch name automatically and removed manual nicknames from the lobby.
- Fixed freezing when selecting hostname-based public nodes.
- Improved network startup, room scanning, and disconnect cleanup.
- Fixed connected UDP behavior and bounded queued traffic.
- Fixed overlay focus, font memory use, and Chinese glyph fallback.
- Fixed update delivery after the monthly traffic allowance resets.
- Improved appointment storage and interrupted backup recovery.
- Clarified errors for keyboard input, language saving, and room actions.

Update in the app or install the SD ZIP, then restart Atmosphère.
