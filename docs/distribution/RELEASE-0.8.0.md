## English

Choose where to host before opening a public room. Press **Y** in the lobby to see each node's region and connection measured by your Switch. Pick a node, return to the game and create a local-wireless room. Recommendations use your network; they cannot predict future guests' connections.

The unified lobby still lists rooms across nodes. Filter by game or region, select a room and check your own path before joining its actual node. Native LAN Play transport now supports standard and fork discovery, joining, game UDP and game TCP. A live session keeps its selected node; recovery never silently moves it elsewhere.

**Test together** is optional: share a temporary code and compare everyone's measurements. No account or additional server is needed. English and Chinese help are included.

Install the matching SD package, or use the in-app updater on 0.7.0 and restart Atmosphère. Host tests, cross-builds and public-node protocol checks are recorded in [validation](VALIDATION.md). Physical two-Switch games, network-switch recovery and comparative game latency still require testing; node RTT is not end-to-end game latency.

## 中文

一个人也能选线路建公共房：大厅按 **Y**，看节点地区和 Switch 实测连接，选好后回游戏创建本地无线房间。推荐只根据你的网络，不能预知后来加入者的网络。

统一大厅继续汇总各节点房间，可按游戏、地区筛选。选房后检测你到该房间节点的连接，再直接加入。新增标准版和分支版 LAN Play 原生建房、搜索、加入及游戏 UDP/TCP 传输。对局锁定所选节点，断线恢复不会擅自换服。

可选「和好友一起测速」：分享临时码，共同比较线路，无需账号或新增服务器。中英文教程同步更新。

合并同版 SD 包，或在 0.7.0 内在线更新，完成后重启虚拟系统。自动测试、交叉构建与公网协议检查见[验证记录](VALIDATION.md)。双 Switch 游戏、切网恢复和实际游戏延迟对比仍待实测；节点延迟不等于对局延迟。
