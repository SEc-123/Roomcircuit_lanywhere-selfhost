## English

LANywhere now checks for updates in the app. Select **Update**, close the game, then download and install. Restart Atmosphère when prompted.

The updater verifies the release signature and installs the app, background module and overlay together. Settings and appointments are preserved. Interrupted installations can be restored through **LANywhere Recovery**.

Install this first updater-enabled version using the full SD ZIP. Protocol, signature and interrupted-installation tests passed. Updating and power-loss recovery on a physical Switch still require verification.

## 中文

新增应用内在线更新。打开应用后检查新版，点「更新」，关闭游戏后下载安装，完成后重启虚拟系统。

更新前校验发布签名，应用、后台和浮层一起安装，保留设置和约局。安装中断时可打开 **LANywhere Recovery** 恢复。

首次安装这个带更新器的版本仍需合并完整 SD 包。下载协议、签名校验和中断恢复测试通过，实体 Switch 更新与断电恢复仍待实测。
