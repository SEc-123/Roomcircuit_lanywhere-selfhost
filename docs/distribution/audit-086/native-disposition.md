# Native sysmodule report disposition

Reviewed the HTML native appendix and Markdown native findings against the original 0.8.6 tree and implemented the following local changes. The source/build validation is separate from physical Switch acceptance.

| Finding | Assessment and correction |
| --- | --- |
| HTML B-01, B-02, A-06 NIFM/MTU | Confirmed early failure resource leak and unsafe profile restoration. Initialization no longer changes the shared Wi-Fi MTU. Existing transports fragment bounded outer datagrams, and local LDN info packets fit ordinary 1280 MTU. NIFM request creation, local mode, submission and polling are transactional. Every created request is canceled and closed, including early failure. OnHold polling has a ten-second deadline. Synchronous Horizon calls still depend on kernel/service completion. |
| B-03, Markdown P0-1 | Confirmed unlimited room/physical ScanResp map growth. Both scan routes accept replies only in their corresponding scan window and apply the game's filter before the eight-entry bound. Direct protocol packet buffers, scan snapshots and the LDN worker stack use the existing malloc pool with paired frees and failure checks, leaving session objects on the C++ pool. The C++ pool grows from 128 to 512 KiB. Ordinary new now fails fast when allocation fails instead of constructing at null. This improves bounded expected-use capacity; it does not guarantee survival of arbitrary local object/resource exhaustion. |
| Markdown P0-2 handles | The original 128 limit has little headroom against 48 accepted sessions and service/thread/events. Raised to 256. Event creation now returns its failure instead of its constructor unconditionally aborting. Domain objects and global resource limits remain finite, so a universally safe maximum cannot be inferred from a session count alone. |
| B-04, B-05, B-08 | Confirmed event disposal and invalid call sequence defects. Destructor calls Finalize. It first stops/joins the LDN worker, then deletes the event under the event lock. Initialize/Finalize are serialized, Attach rejects missing event, callbacks take the same event lock, and missing/default callbacks are safe. |
| B-09 | Confirmed lost-stop race. The stop flag is atomic, set before thread start, and never cleared by the worker entry. Finalize joins outside the worker's state lock. |
| B-10 and A-07 logging | Confirmed diagnostic file operations could abort and hex/text access was unsynchronized. SD failures now disable diagnostic logging, close handles and return. Text and hex share the recursive log lock. Both ldn_mitm.log and BSD debug.log are bounded at 256 KiB. |
| R-01 transport state | Confirmed final transport failure did not consistently reach LDN. All online game roles track their online association. The worker preserves connected state during recovery, but clears nodes, releases owned resources, sets SignalLost and emits Error when recovery finishes unsuccessfully, including direct hosts and private-room users. |
| R-02/R-06 concurrency | Confirmed destruction/read races. The static control buffer is replaced by an instance buffer (Markdown P2-1). Mode-changing IPC operations serialize on a lifecycle lock. Shared state/physical sockets and callbacks use a recursive poll lock. Long scan/join waits release that lock while retaining lifecycle ownership, so workers can deliver replies. NetworkInfo and change flags are read/cleared under the same lock. |
| R-03 physical framing | Confirmed terminal-zero overread, retained TCP frames and short-send loss. Bounds are checked before reading. Complete retained TCP frames are consumed without another kernel wakeup. TCP sends complete short writes with a bounded nonblocking loop or close an incomplete stream. Decompression rejects an expansion that would exceed output capacity. Stack VLAs are replaced with fixed bounded arrays. |
| R-04 mixed online/physical ingress | Confirmed local state pollution before server rejection. Any online host binds its physical listener to loopback, refuses physical Scan requests and rejects physical station acceptance. Physical-only acceptance respects room capacity and local communication version. |
| R-05/A-05 outputs and local input | Confirmed uninitialized padding and narrowing/bounds gaps. NetworkConfig is fully zeroed, NodeLatestUpdate reserved bytes are zeroed, failed IP query outputs start at zero, advertise size is checked before narrowing, scan capacity and SSID length are checked, and unterminated UserConfig names fail without strcpy. Initialize/None state guards now cover scan, advertising, connection and mode transitions. |
| R-07 fork stream | Confirmed interoperability limitation of the legacy fork wire. Existing protocol has no reliable ordered sequence/ack exchange. An unilateral new packet layout would break legacy peers. Standard transport remains preferred. No claim of reliable legacy fork TCP or universal game compatibility is added. |
| A-01 ROOM | Confirmed weaker native-room checks. Every accepted provider now checks header/member count/exact length, code, own member/index/IP/token, unique allowed virtual IPs, and expected CREATE/JOIN game identity. Malformed new admissions are left explicitly. |
| A-02 registration rollback | Confirmed lease linger on normal new room admission followed by UDP failure. All fresh CREATE/JOIN paths send LEAVE on registration failure. RESUME still keeps its recoverable lease. |
| A-03 direct configuration | Confirmed failed socket replacement could leave configured=true/socket=-1. Configuration now clears the flag until socket/nonblocking setup succeeds and never reuses an invalid fd. Failed heartbeat replacement retains the old usable socket. |
| A-04 local-only fallback | The legacy UI visibility control conflicts with managed host routing. The app hides the legacy local-only toggle when the current node API is present; old-module fallback is retained. Native online hosts are isolated from physical ingress. |
| B-06/B-07 UDP API and lifetime | Connected UDP, descriptor aliases, shutdown, address queries, per-process cleanup and peer filtering are corrected and covered by actual-hook tests. Batch virtual UDP remains explicitly unsupported. Markdown claim that Poll/Select are entirely absent is incorrect; both handlers exist in the baseline. The HTML connected-UDP, alias and lifetime findings are separate and valid. |
| A-07 appointment errors | Subscription-read failures return an IPC error, and worker startup must succeed before new enabled subscriptions are saved. Notifications still depend on an Ultrahand consumer, use a finite queue and do not promise cross-restart exactly-once delivery. Server character normalization can change system-name symbols. |
| Markdown P1-3 stack budget | The alleged exact peak has no captured hardware stack trace. The LDN worker stack grows to 32 KiB and old protocol VLAs are removed. Main HIPC threads remain 16 KiB. A whole-program worst-case proof and installed-plugin resource headroom remain physical acceptance requirements. |

## Verification

- `native_lifecycle_test.py` runs actual production initialize/finalize/worker through injected NIFM request, submit, wait, UDP and thread failures, checks create/close balance and delayed-start stop race.
- `native_event_test.py` runs actual event methods with concurrent callbacks/Finalize/Attach and validates destructor ordering and early failures.
- `native_protocol_test.py` compiles actual physical protocol source with ASan/UBSan, terminal-zero input, output expansion, coalesced/partial frames and deterministic short TCP sends.
- `native_logging_test.py` runs actual diagnostic and BSD logger functions with SD operation failures, concurrent hex/text, bounded growth and balanced close.
- `native_state_test.py` runs actual state/message/output code for final transport loss, recovery preservation, filtered eight-row scan cap and zeroed output padding.
- Existing LCID entry, GameRoute, transport recovery, room-password, and 111-case proxy/Handshake regressions pass after their input fixtures represent legitimate ROOM metadata and IPC states.

All 127 host suites and the Switch cross-build passed. After the last scan-filter change, six affected native regressions passed again. Final app/sysmodule/overlay metadata and all 324 native source fingerprints were verified. Physical-console acceptance remains pending.

## Retained service boundaries

Runtime A-06: twelve synchronous IPC workers can still be occupied by enough indefinitely blocked recv/poll/accept calls. NIFM has an OnHold budget, but this is not a general asynchronous IPC scheduler or a guarantee for arbitrary workloads. The supplied audit did not reproduce this with a normal commercial game.

Private LDN and complex admission policies are not fully emulated. RegisterClient remains a compatibility stub; the UDP descriptor cleanup is implemented separately. These are support boundaries, not claims of complete Horizon service equivalence.
