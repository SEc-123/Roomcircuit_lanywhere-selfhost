# Source and scope

RoomCircuit native-online development uses the OpenPak account core and pinned protocol references. The new independent backend and console validation code in this project use AGPL-3.0-only unless a file states otherwise. The Atmosphere patch and its derived module remain GPL-2.0-only; see `native-client/LICENSE.Atmosphere` and its pinned source and build receipts. The `wire` package includes the corresponding upstream attribution and license.

This is an independent service implementation. Account validation, device approval and game authorization belong to this service. Controlled protocol tests do not establish compatibility with every title or a completed retail-console session. No official Nintendo credentials or private console keys are packaged.
